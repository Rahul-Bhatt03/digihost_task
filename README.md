# React Developer Assignment – Globus Homepage

This project is a responsive UI implementation of the Globus Homepage design provided via Figma. The application is built using **React.js** and **Tailwind CSS**.

## Features
- Fully responsive design
- Component-based architecture
- Clean and readable code
- Proper use of Tailwind CSS utilities

## Setup Instructions

1. **Clone the repository**
```bash
git clone <repository-link>

2. Navigate to the project directory
cd project-directory

3.Install dependencies
npm install

4.Run the development server
npm run dev



Note: Due to the 2-day timeline, I was unable to implement a small section of the Figma design, which has been left as is. I focused on ensuring the majority of the design is implemented with clean, responsive code.
